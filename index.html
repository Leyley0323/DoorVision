Project Description

DoorVision is an intelligent home security system designed for homeowners and renters seeking greater peace of mind. While many existing security solutions rely on traditional sensors, DoorVision enhances protection by using facial recognition to distinguish authorized users from potential intruders. The system secures the home’s front door by allowing access only to approved individuals. When a recognized user approaches, DoorVision automatically unlocks the door. If unauthorized activity is detected, the system sends real-time alerts to the homeowner through a mobile application, enabling immediate awareness and response. By combining vision-based authentication with smart alerts, DoorVision focuses on preventing unauthorized entry before it occurs. This senior design project integrates embedded systems, artificial intelligence, sensors, motors, and mobile app development to deliver a modern, reliable approach to residential security.
